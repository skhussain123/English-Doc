

"Able to" English mein istimaal hota hai kisi shakhs ya cheez ke kisi kaam ko karne ke qabil (capable) hone ko batane ke liye. Urdu mein is ka matlab hota hai "qabil hona", "kar sakna", ya "salahiyat rakhna".

### Able to
**Subject + is/am/are/was/were + able to + verb (1st form)**

1. She is able to speak English.<br>
(Woh angrezi bolne ke qabil hai / bol sakti hai)

2. They were able to solve the problem.<br>
(Woh masla hal karne ke qabil thay / unhon ne masla hal kar liya)

3. I will be able to complete the work tomorrow.
(Main kal kaam mukammal kar sakunga)

4. Are you able to understand this?<br>
(Kya tum ye samajhne ke qabil ho?)

5. He wasn’t able to come to the party.<br>
(Woh party mein nahi aa saka)

### Tense ke mutabiq use:
| Tense   | Form              | Example                          |
| ------- | ----------------- | -------------------------------- |
| Present | am/is/are able to | She **is able to** help.         |
| Past    | was/were able to  | They **were able to** finish it. |
| Future  | will be able to   | You **will be able to** do this. |
