


## 1. "Can" 
ka use English mein ability (صلاحیت), permission (اجازت), aur possibility (امکان) dikhane ke liye hota hai.

#### 1. Ability (صلاحیت)
| Sentence               | Urdu Translation        |
| ---------------------- | ----------------------- |
| I can swim.            | میں تیر سکتا ہوں۔       |
| She can speak English. | وہ انگریزی بول سکتی ہے۔ |


#### 2. Permission (اجازت)
| Sentence              | Urdu Translation                |
| --------------------- | ------------------------------- |
| Can I go now?         | کیا میں اب جا سکتا ہوں؟         |
| You can use my phone. | تم میرا فون استعمال کر سکتے ہو۔ |


#### 3. Possibility (امکان)
| Sentence                    | Urdu Translation          |
| --------------------------- | ------------------------- |
| It can rain today.          | آج بارش ہو سکتی ہے۔       |
| This road can be dangerous. | یہ سڑک خطرناک ہو سکتی ہے۔ |

## 2. "May" ka Use:
"May" aur "Can" dono ka use English mein hota hai lekin dono ka meaning aur tone thoda different hota hai. Neeche detail mein dono ka comparison diya gaya hai:

**Formal Permission (رسمی اجازت)**

* May I come in?
(کیا میں اندر آ سکتا ہوں؟)

* You may go now.
(آپ جا سکتے ہیں۔)

**Possibility (امکان)**

* It may rain today.
(شاید آج بارش ہو جائے۔)

* He may come tomorrow.
(شاید وہ کل آئے۔)

### "Can" vs "May" – Comparison Table:
| Usage           | Can                    | May                            |
| --------------- | ---------------------- | ------------------------------ |
| **Ability**     | I can lift this box.   | ❌ May is not used for ability. |
| **Permission**  | Can I go out? (casual) | May I go out? (formal/polite)  |
| **Possibility** | It can be dangerous.   | It may be dangerous.           |
| **Tone**        | Informal / Friendly    | Formal / Polite / Cautious     |



## "Should"
"Should" ka use English mein naseehat (advice), zimmedari (duty), ya kisi kaam ko karna chahiye ya nahi chahiye batane ke liye hota hai.

| English | Urdu      |
| ------- | --------- |
| should  | **چاہیے** |


### 1. Advice dene ke liye (نصیحت / مشورہ):

* You should rest.
(تمہیں آرام کرنا چاہیے۔)

* He should study hard.
(اسے محنت سے پڑھنا چاہیے۔)


### 2. Obligation / Duty (ذمہ داری):

* We should help poor people.
(ہمیں غریبوں کی مدد کرنی چاہیے۔)


### 3. Expectation (توقع):

* The train should arrive by 10.
(ٹرین کو 10 بجے تک آ جانا چاہیے۔)

### 4. Negative form (نہیں کرنا چاہیے):

* You should not smoke.
(تمہیں سگریٹ نہیں پینا چاہیے۔)
