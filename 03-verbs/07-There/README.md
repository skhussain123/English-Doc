


## 1. There as "Mojoodgi" (Existence) dikhane ke liye
* Yeh batata hai ke koi cheez mojood hai ya nahi.

#### Structure
* There is = koi ek cheez hai
* There are = bohat si cheezen hain

#### Examples
* There is a cat on the roof.
   * → Ek billi chhat par hai.
* There are two fans in the room.
   * → Room mein do pankay hain.   

| Tense           | Singular       | Plural          | Roman Urdu Example                          |
| --------------- | -------------- | --------------- | ------------------------------------------- |
| Present         | There is       | There are       | There is a car outside. (Bahar ek car hai.) |
| Past            | There was      | There were      | There were many people. (Bohat log thay.)   |
| Future          | There will be  | There will be   | There will be rain. (Barish hogi.)          |
| Present Perfect | There has been | There have been | There has been a mistake. (Ghalti hui hai.) |
| Past Perfect    | There had been | There had been  | There had been a fire. (Aag lagi thi.)      |


## 2. There as "Jagah" (Place adverb)
* Yeh dikhata hai ke koi jagah ka zikar ho raha hai.

#### Example
* He is there.
   * → Woh wahan hai.
* Don’t go there.
   * → Wahan mat jao.
* I was there yesterday.
   * → Main kal wahan tha.


## 3. There as Introductory Words
* Jab sentence ka start "there" se hota hai — taake hum emphasis dain.

#### Examples
* There comes a time when you have to choose.
   * → Aik waqt aata hai jab faisla lena parta hai.
* There seems to be a problem.
   * → Lagta hai koi masla hai.


## 4. There with Modals (Can, Should, Must etc.)
* Yeh future ya possibility dikhata hai.
#### Examples
* There can be a problem.
   * → Koi masla ho sakta hai.
* There should be a doctor.
   * → Wahan doctor hona chahiye.
* There must be another way.
   * → Zaroor koi aur raasta hoga.


## 5. There in Questions
* Sawalon mein bhi there ka use hota hai:

#### Examples
* Is there any water?
   * → Kya koi paani hai?
* Are there any students?
  * → Kya koi students hain?
* Will there be a meeting tomorrow?
  * → Kya kal meeting hogi?


###  Quick Summary
| Use Type          | English Example         | Roman Urdu Meaning     |
| ----------------- | ----------------------- | ---------------------- |
| Mojoodgi          | There is a book.        | Ek kitab mojood hai.   |
| Jagah dikhana     | He went there.          | Woh wahan gaya.        |
| Sawal banana      | Is there a pen?         | Kya wahan aik pen hai? |
| Future show karna | There will be a storm.  | Aandhi aane wali hai.  |
| Possibility       | There can be a mistake. | Ghalti ho sakti hai.   |
