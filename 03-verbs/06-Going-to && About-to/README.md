

## going to" and "about to

### 1. Going to
* Used to express future intentions, plans, or predictions based on current evidence.
```bash
Subject + am/is/are + going to + base verb
```
1. I am going to start a business.
2. You have already planned or decided.

3. Look at those dark clouds! It's going to rain.
5. You see clouds, so you predict rain.


### 2. About to
* Used when something is going to happen very soon, almost immediately.
```bash
Subject + am/is/are + about to + base verb
```
##### When to use
1. I am about to leave.
2. You are going to leave in the next moment
3. The show is about to begin.
4. It will start in a few seconds

| Phrase   | Meaning                              | When to Use                 | Example                          |
| -------- | ------------------------------------ | --------------------------- | -------------------------------- |
| Going to | Future plan, decision, or prediction | Later (but not immediate)   | I’m going to call her tomorrow.  |
| About to | Very soon, almost now                | Immediately or very shortly | I’m about to call her right now. |

| Going to                               | About to                                    |
| -------------------------------------- | ------------------------------------------- |
| I'm going to cook dinner tonight.      | I'm about to start cooking dinner.          |
| They are going to move next month.     | They are about to move now.                 |
| She’s going to take the exam tomorrow. | She’s about to take the exam (in a moment). |
| We’re going to watch a movie later.    | The movie is about to start.                |
| I'm going to sleep in a while.         | I'm about to fall asleep.                   |
