
### Want to
"Want to" aur "Wanted to" dono English mein chahna (چاہنا) ke liye use hotay hain, lekin tense (waqt) ke mutabiq farq hota hai.


### Wanted to
Istemaal jab koi shakhs pehle kisi kaam ko karna chahta tha, ya usne kuch karne ki koshish ki.

### Wants to
"Wants to" tab lagta hai jab "he, she, it" ya koi singular name ho.


#### Want to with different ways:
| Expression        | Urdu Meaning / Nuance                           | Use Case Example                     | English Example              |
| ----------------- | ----------------------------------------------- | ------------------------------------ | ---------------------------- |
| **want to**       | simply chahna (niyat/khwahish)                  | Main parhna chahta hoon              | I want to study.             |
| **want**          | kisi cheez ki khwahish                          | Main aik naya phone chahta hoon      | I want a new phone.          |
| **need to**       | zarurat (majboori ya necessity)                 | Mujhe jana zaruri hai                | I need to go.                |
| **should**        | mashwara ya zimmedari (light obligation)        | Tumhein parhna chahiye               | You should study.            |
| **must**          | sakht zarurat / strong obligation               | Tumhein kaam har hal mein karna hoga | You must do the work.        |
| **ought to**      | moral duty / strong advice (formal)             | Tumhein sach bolna chahiye           | You ought to tell the truth. |
| **want to be**    | banna chahta hoon (profession, state, role)     | Main doctor banna chahta hoon        | I want to be a doctor.       |
| **would like to** | narmi se chahna (formal/polite version of want) | Main chai lena chahta hoon           | I would like to have tea.    |


### Difference Between (Want to And Wants to)
| Subject       | Correct Form |
| ------------- | ------------ |
| I             | want to      |
| You           | want to      |
| We            | want to      |
| They          | want to      |
| He / She / It | wants to     |
| Ali / Sara    | wants to     |
