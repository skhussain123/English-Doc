

### 1. Let
ab aap kisi ko ijazat dete ho kuch karne ki, ya order ya request karte ho.


| **Subject Pronoun** | **Object Pronoun** | **Urdu Meaning**          |
| ------------------- | ------------------ | ------------------------- |
| I                   | me                 | میں → مجھے                |
| You                 | you                | تم / آپ → تمہیں / آپ کو   |
| He                  | him                | وہ (مرد) → اسے            |
| She                 | her                | وہ (عورت) → اسے           |
| It                  | it                 | یہ / وہ (چیز) → اسے / اسے |
| We                  | us                 | ہم → ہمیں                 |
| They                | them               | وہ سب → انہیں             |
| Who                 | whom               | کون → کسے / جسے           |



1. Let him go
(Usay jane do.)

2. Let me help you.
(Mujhe tumhari madad karne do.)

3. Let her speak.
(Usay bolne do.)

### 2. Let's = Let us
* Jab aap kisi ko kisi kaam ke liye suggest karte ho ya invite karte ho mil kar kuch karne ke liye.

1. Let's go.
(Chalo chalein.)

2. Let's eat something.
(Aao kuch khate hain.)

3. Let's start the meeting.
(Aao meeting shuru karte hain.)
