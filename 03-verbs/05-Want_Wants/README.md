

### Want, Wants, Should, Must, Need" - Comparison Table
| Verb       | Type                   | Meaning in Urdu         | Use/Structure                                                      | Example Sentence                        | Urdu Translation                                        |
| ---------- | ---------------------- | ----------------------- | ------------------------------------------------------------------ | --------------------------------------- | ------------------------------------------------------- |
| **Want**   | Main verb              | chahna                  | Subject + want + to + verb                                         | I want to eat.                          | Main khana chahta hoon.                                 |
| **Wants**  | Main verb (3rd person) | chahna                  | He/She/It + wants + to + verb                                      | She wants to study.                     | Wo parhna chahti hai.                                   |
| **Should** | Modal verb             | chahiye (suggestion)    | Subject + should + base verb                                       | You should sleep early.                 | Tumhein jaldi sona chahiye.                             |
| **Must**   | Modal verb             | zaroori hai / lazmi hai | Subject + must + base verb                                         | You must wear a helmet.                 | Tumhein helmet pehnana zaroori hai.                     |
| **Need**   | Verb / modal (semi)    | zarurat hona            | (i) Subject + need to + verb<br>(ii) Negative: needn't + base verb | I need to go now.<br>You needn't worry. | Mujhe ab jana hai.<br>Tumhein fikar nahi karni chahiye. |


#### 🔹 Want vs Wants

* "Want" = I/We/You/They
* "Wants" = He/She/It
➤ Want ke baad hamesha "to + verb" aata hai.


#### 🔹 Should

* Suggestion ya advice ke liye use hota hai.
➤ "Tumhein aisa karna chahiye" type sentences ke liye.


#### 🔹 Must
* Strong necessity ya obligation dikhata hai.
➤ "Yeh zaroori hai" jese sentences ke liye.


#### Need
* Jab kisi cheez ki zarurat ho.
* "Need to" bhi hota hai (normal verb).
* "Needn't" ka matlab hota hai "zarurat nahi hai".
