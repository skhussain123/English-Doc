

### Definition (تعریف):
Past Perfect Continuous Tense aisa tense hota hai jo kisi kaam ke mazi mein shuru ho kar kuch der tak jaari rehne ko ظاہر کرتا hai, lekin wo kaam mazi mein kisi aur kaam ya waqt se pehle ho chuka hota hai.

**"رہا تھا، رہی تھی، رہے تھے" + "سے"**

| Sentence Type   | Structure                                       | Urdu                                         |
| --------------- | ----------------------------------------------- | -------------------------------------------- |
| ✅ Affirmative   | Subject + had been + verb + ing + since/for     | فاعل + مدت سے + فعل + رہا/رہی/رہے تھا        |
| ❌ Negative      | Subject + had not been + verb + ing + since/for | فاعل + مدت سے + فعل + نہیں + رہا/رہی/رہے تھا |
| ❓ Interrogative | Had + subject + been + verb + ing + since/for?  | کیا + فاعل + مدت سے + فعل + رہا/رہی/رہے تھا؟ |


| Use Case                                                                     | Example                                                  | Urdu                                               |
| ---------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------- |
| 1. A past action that was happening for some time before another past action | He **had been reading** for two hours **before I came**. | جب میں آیا، وہ دو گھنٹے سے پڑھ رہا تھا۔            |
| 2. Showing cause and effect in the past                                      | She was tired because she **had been working** all day.  | وہ تھکی ہوئی تھی کیونکہ وہ سارا دن کام کر رہی تھی۔ |


* Since – point in time (since morning, since 2010)
* For – duration of time (for 2 hours, for 3 days)
