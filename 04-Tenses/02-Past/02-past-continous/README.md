


Past Continuous Tense wo tense hai jo kisi aise kaam ko ظاہر کرتا ہے jo mazi ke kisi waqt mein ho raha tha, lekin mukammal nahi hua tha.
**"رہا تھا، رہی تھی، رہے تھے" ka aana**


| Sentence Type   | Structure                             | Urdu                                |
| --------------- | ------------------------------------- | ----------------------------------- |
| ✅ Affirmative   | Subject + was/were + verb + ing       | فاعل + رہا/رہی/رہے تھا + فعل        |
| ❌ Negative      | Subject + was/were + not + verb + ing | فاعل + نہیں + رہا/رہی/رہے تھا + فعل |
| ❓ Interrogative | Was/Were + subject + verb + ing?      | کیا + فاعل + رہا/رہی/رہے تھا + فعل؟ |


| Subject              | Helping Verb |
| -------------------- | ------------ |
| I, He, She, It, Name | **was**      |
| You, We, They        | **were**     |



| Use Case                             | Example                                     | Urdu                                        |
| ------------------------------------ | ------------------------------------------- | ------------------------------------------- |
| 1. Past action in progress           | He was reading a book.                      | وہ کتاب پڑھ رہا تھا۔                        |
| 2. Interrupted action in past        | I was sleeping when you called.             | جب تم نے فون کیا میں سو رہا تھا۔            |
| 3. Background scenes in storytelling | The sun was setting, and birds were flying. | سورج غروب ہو رہا تھا اور پرندے اُڑ رہے تھے۔ |
