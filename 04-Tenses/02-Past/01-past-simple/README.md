

Past Indefinite Tense wo tense hai jo mazi ke mukammal (ختم شدہ) kaam ko ظاہر karta hai.
Yeh kisi specific waqt mein hone wale actions ke liye use hota hai.

* "گیا، گئے، کی، کیا، تھا، تھیں، تھی" jese lafzon ka istemal.

| Sentence Type   | Structure                              | Urdu Structure               |
| --------------- | -------------------------------------- | ---------------------------- |
| ✅ Affirmative   | Subject + 2nd form of verb + object    | فاعل + فعل (ماضی) + مفعول    |
| ❌ Negative      | Subject + did not + base verb + object | فاعل + نے نہیں + فعل + مفعول |
| ❓ Interrogative | Did + subject + base verb + object?    | کیا + فاعل + فعل + مفعول؟    |


| Use Case                       | Example                        | Urdu                                   |
| ------------------------------ | ------------------------------ | -------------------------------------- |
| 1. **Completed past action**   | He watched a movie last night. | اُس نے رات فلم دیکھی۔                  |
| 2. **Series of past events**   | I came, I saw, I conquered.    | میں آیا، میں نے دیکھا، میں نے فتح کیا۔ |
| 3. **Storytelling or history** | The king ruled for 20 years.   | بادشاہ نے 20 سال حکومت کی۔             |
