

### efinition (تعریف):
Future Perfect Continuous Tense wo tense hai jo batata hai ke mustaqbil ke kisi waqt tak koi kaam ek muddat se chal raha hoga.

**"رہا ہوگا، رہی ہوگی، رہے ہوں گے ایک مدت سے"**

| Sentence Type   | Structure                                                          | Urdu                                          |
| --------------- | ------------------------------------------------------------------ | --------------------------------------------- |
| ✅ Affirmative   | Subject + **will have been** + verb + **ing** + time reference     | فاعل + رہا/رہی/رہے ہوں گے + ایک مدت سے        |
| ❌ Negative      | Subject + **will not have been** + verb + **ing** + time reference | فاعل + نہیں + رہا/رہی/رہے ہوں گے + ایک مدت سے |
| ❓ Interrogative | Will + subject + **have been** + verb + **ing** + time reference?  | کیا + فاعل + ایک مدت سے + رہا/رہی/رہے ہوں گے؟ |




| Use Case                               | Example                                       | Urdu                                              |
| -------------------------------------- | --------------------------------------------- | ------------------------------------------------- |
| Action in progress over time in future | I will have been working for 5 hours by 9 PM. | میں رات 9 بجے تک پانچ گھنٹے سے کام کر رہا ہوں گا۔ |
| To show **duration** of future actions | She will have been studying since morning.    | وہ صبح سے پڑھ رہی ہوگی۔                           |
