


### Definition (تعریف):
Future Indefinite Tense wo tense hai jo mustaqbil (آنے والے وقت) mein kisi kaam ke hone ko ظاہر karta hai.
**"گا، گی، گے" ka aana**

| Sentence Type   | Structure                                    | Urdu                         |
| --------------- | -------------------------------------------- | ---------------------------- |
| ✅ Affirmative   | Subject + **will/shall** + base verb         | فاعل + گا/گی/گے + فعل        |
| ❌ Negative      | Subject + **will not/shall not** + base verb | فاعل + نہیں + گا/گی/گے + فعل |
| ❓ Interrogative | Will/Shall + subject + base verb?            | کیا + فاعل + گا/گی/گے + فعل؟ |



* Will ka use sab subjects ke sath hota hai (modern usage).
* Shall sirf “I” aur “We” ke sath suggestions/promises ke liye use hota hai (formal English).
