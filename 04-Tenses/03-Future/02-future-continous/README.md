

###  Definition (تعریف):
Future Continuous Tense aisa tense hai jo mustaqbil (آنے والے وقت) mein kisi kaam ke chalne ko ظاہر karta hai — yani aane wale waqt mein koi kaam ho raha hoga.

**"رہا ہوگا، رہی ہوگی، رہے ہوں گے"**

| Sentence Type   | Structure                              | Urdu                                   |
| --------------- | -------------------------------------- | -------------------------------------- |
| ✅ Affirmative   | Subject + **will be** + verb + ing     | فاعل + رہا/رہی/رہے ہوں گے + فعل        |
| ❌ Negative      | Subject + **will not be** + verb + ing | فاعل + نہیں + رہا/رہی/رہے ہوں گے + فعل |
| ❓ Interrogative | Will + subject + **be** + verb + ing?  | کیا + فاعل + رہا/رہی/رہے ہوں گے؟ + فعل |



| Use Case                             | Example                                  | Urdu                                    |
| ------------------------------------ | ---------------------------------------- | --------------------------------------- |
| 1. Future action in progress         | I will be studying at 8 PM.              | میں آٹھ بجے پڑھ رہا ہوں گا۔             |
| 2. Prediction of ongoing event       | They will be traveling tomorrow morning. | وہ کل صبح سفر کر رہے ہوں گے۔            |
| 3. Polite inquiry about future plans | Will you be joining us for dinner?       | کیا آپ ہمارے ساتھ کھانے پر شامل ہوں گے؟ |
