


Present Perfect Tense wo tense hota hai jo abhi abhi mukammal hone wale kaam, zindagi mein kabhi hone wale kaam, ya aise kaam jo past mein shuru hue aur ab tak relevant hain ko ظاہر karta hai۔

**"چکا ہے، چکی ہے، چکے ہیں" کا آنا۔**

| Sentence Type   | Structure                                   | Urdu                     |
| --------------- | ------------------------------------------- | ------------------------ |
| ✅ Affirmative   | Subject + has/have + 3rd form of verb       | میں کام کر چکا ہوں۔      |
| ❌ Negative      | Subject + has/have + not + 3rd form of verb | میں کام نہیں کر چکا ہوں۔ |
| ❓ Interrogative | Has/Have + Subject + 3rd form of verb?      | کیا میں کام کر چکا ہوں؟  |



| Subject           | Helping Verb |
| ----------------- | ------------ |
| I, You, We, They  | **have**     |
| He, She, It, Name | **has**      |


| Use Case                      | Example                          | Urdu                            |
| ----------------------------- | -------------------------------- | ------------------------------- |
| 1. **Recent actions**         | I have just eaten.               | میں نے ابھی ابھی کھایا ہے۔      |
| 2. **Life experience**        | She has never traveled abroad.   | وہ کبھی بیرونِ ملک نہیں گئی۔    |
| 3. **Unfinished time period** | We have studied a lot this week. | ہم نے اس ہفتے بہت پڑھائی کی ہے۔ |
| 4. **Change over time**       | He has become more responsible.  | وہ زیادہ ذمہ دار بن گیا ہے۔     |
