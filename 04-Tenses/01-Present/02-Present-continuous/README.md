

### Definition 
Present Continuous Tense wo tense hai jo iss waqt ho rahe kaam (current actions), temporary situations, ya near future plans ko ظاہر karta hai.

| Type            | Structure                              | Urdu Formula                       |
| --------------- | -------------------------------------- | ---------------------------------- |
| ✅ Affirmative   | Subject + am/is/are + verb + ing       | فاعل + رہا/رہی/رہے ہے + فعل        |
| ❌ Negative      | Subject + am/is/are + not + verb + ing | فاعل + نہیں + رہا/رہی/رہے ہے + فعل |
| ❓ Interrogative | Am/Is/Are + subject + verb + ing?      | کیا + فاعل + رہا/رہی/رہے ہے + فعل؟ |


| Subject       | Helping Verb |
| ------------- | ------------ |
| I             | am           |
| He, She, It   | is           |
| You, We, They | are          |


| Use Case                | Example                           | Urdu                               |
| ----------------------- | --------------------------------- | ---------------------------------- |
| 1. **Current action**   | I am writing now.                 | میں ابھی لکھ رہا ہوں۔              |
| 2. **Temporary action** | She is staying with her aunt.     | وہ اپنی خالہ کے پاس ٹھہری ہوئی ہے۔ |
| 3. **Near future**      | We are going to the market today. | ہم آج مارکیٹ جا رہے ہیں۔           |
| 4. **Trends or change** | People are becoming smarter.      | لوگ زیادہ ہوشیار ہوتے جا رہے ہیں۔  |
