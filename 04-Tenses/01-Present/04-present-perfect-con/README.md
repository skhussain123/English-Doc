

### Definition 
Present Perfect Continuous Tense aisa tense hota hai jo kisi kaam ke mazi mein shuru hone aur ab tak jaari hone ko ظاہر کرتا hai.

**"رہا ہے، رہی ہے، رہے ہیں (مدت سے)"**
* "سے" ka lafz aam tor par aata hai (e.g., "دو گھنٹے سے", "صبح سے", "کئی دنوں سے")

| Sentence Type   | Structure                                            | Urdu                          |
| --------------- | ---------------------------------------------------- | ----------------------------- |
| ✅ Affirmative   | Subject + has/have been + verb + ing + since/for     | میں دو گھنٹوں سے پڑھ رہا ہوں۔ |
| ❌ Negative      | Subject + has/have not been + verb + ing + since/for | وہ صبح سے کام نہیں کر رہا ہے۔ |
| ❓ Interrogative | Has/Have + subject + been + verb + ing + since/for?  | کیا تم رات سے محنت کر رہے ہو؟ |


| Subject           | Helping Verb  |
| ----------------- | ------------- |
| I, You, We, They  | **have been** |
| He, She, It, Name | **has been**  |


| Use Case                                           | Example                             | Urdu                            |
| -------------------------------------------------- | ----------------------------------- | ------------------------------- |
| Kaam jo mazi mein shuru hua ho aur ab tak jaari ho | I have been reading for two hours.  | میں دو گھنٹوں سے پڑھ رہا ہوں۔   |
| Temporary action with duration                     | She has been working since morning. | وہ صبح سے کام کر رہی ہے۔        |
| Repeated action in recent past                     | They have been calling me all day.  | وہ سارا دن مجھے کال کر رہے ہیں۔ |


| Word      | Use For             | Example                                   |
| --------- | ------------------- | ----------------------------------------- |
| **Since** | Exact point in time | since 5 o’clock, since Monday, since 2020 |
| **For**   | Duration of time    | for 2 hours, for 5 days, for a long time  |
